用原生 HTML 和 CSS 搭一个安静的博客

没有框架、没有构建、没有依赖——只有几个文件，和一点耐心。

前段时间我把博客从某个静态站点生成器上搬了下来，换成了最原始的方式：手写 HTML 和 CSS。

朋友问为什么，我说不上来特别宏大的理由。大概是某天打开 node_modules，看见两千多个文件夹，突然觉得有点荒谬——我只是想写点字。

从减法开始

这个站点的全部依赖是零。目录大概长这样：

.
├── index.html
├── about.html
├── posts/
│   └── *.html
└── assets/
    ├── style.css
    ├── blog.js
    └── app.js

没有打包，没有热更新，没有配置文件。改一行 CSS，刷新页面就能看到效果。想加一篇文章，复制一个文件，改掉标题和正文，再在 blog.js 里补一条记录。

少掉的那些东西——插件、主题、构建管线——曾经让我觉得强大，后来发现它们主要是让我在「配置博客」这件事上消耗时间，而不是「写博客」。

用 CSS 变量管理颜色

深浅色切换最省事的做法，是把所有颜色抽成变量：

:root {
  --bg: #fbfaf7;
  --text: #1b1d21;
  --accent: #bf5b3d;
}

[data-theme="dark"] {
  --bg: #101113;
  --text: #e9e7e2;
  --accent: #e8825f;
}

然后在 <html> 上切换 data-theme，整站的颜色就跟着变了。不需要写两套样式，也不需要 JS 去逐个修改元素。

别让页面闪一下

如果主题是在 JS 加载完之后才设置的，用户会先看到一秒白底，再跳到深色——很难看。

解决办法是：把判断逻辑放进 <head> 里，在样式表之前执行。

<script>
  (function () {
    var saved = localStorage.getItem("theme");
    document.documentElement.dataset.theme =
      saved || (matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light");
  })();
</script>

这段代码很短，但它决定了第一眼的感觉。

留白比装饰更难

真正花时间的地方不是功能，是比例。

标题多大、行高多少、卡片之间留多少空隙、正文一行多少字——这些没有标准答案，只能一点一点调。调到最后你会发现，所谓「简洁」，不是少了什么，而是每一处都刚好。

我删掉了很多东西：阴影、渐变、动画、分割线、装饰性图标。留下的每一样都得解释得清自己为什么存在。

最后是部署

静态站点最舒服的一点：扔到任何地方都能跑。

  • GitHub Pages：推上去就有地址
  • Vercel / Netlify：连仓库，自动部署
  • 自己的服务器：把文件夹拷过去就行

没有数据库，没有环境变量，没有冷启动。

有时候我在想，工具的意义是让人更快地抵达想法。如果一个工具让你花在工具上的时间超过了想法本身，那它可能不适合你。

最好的工具，是你忘记它存在的那一个。
